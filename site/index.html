Your workspace, your way

A fully dockable scientific layout

Every tool surface is a pane you can split, drag between regions, tab together, reorder, or hide. Arrange the workspace once and Forge remembers it across restarts.

Dock anythingdrag & drop

Drag a pane's tab to split a region, move it to another edge, or group it with others. The editor, file tree, outline, cell rail, console, history, Python runtime, terminals, Rust kernels, the data viewer, and every inspector are all first-class dockable panes.

Show only what you needView → Panes

Toggle any pane on or off from the View menu, or reset to the default layout at any time. Long panes scroll independently and remember where you left them.

Keyboard-drivenCtrl+1..9 · F6

Jump straight to an inspector with Ctrl+1 through Ctrl+9, cycle panes with F6, and reach every command through the Ctrl+Shift+P palette. A status bar keeps runtime, file, and language-server state in one place.

What's inside

Editor-first, driven by real background work

Each pane is backed by bounded, non-blocking work — imports, diagnostics, indexing, and training all run off the UI thread.

▶

Persistent Rust console

An Evcxr session runs off the UI thread. Cells share state, so setup and data cells feed later ones. Reset the runtime without restarting the app.

⌨

Terminals & kernels

Real embedded system terminals (vim, htop, and all) plus independent Rust REPL kernels — open as many as you like, each a dockable, floatable pane.

▦

Notebook cells

Split scripts into cells with //# %%. Run one, everything above, or all — with per-cell status, output, compiler errors, and timing.

◔

Variables & plots

Live Evcxr variable names and Rust types after every cell. Publish metrics, vectors, and tables from stdout into charts and grids.

⊞

Data viewer

Import CSV, TSV, JSON Lines, Parquet, and Arrow IPC. Virtualized two-axis grids with filter, sort, pin/hide columns, editing, and linked plots.

◈

rust-analyzer

Document sync, inline diagnostics, hover, caret-anchored completion, and Ctrl+click go-to-definition across files.

⌘

Command palette

Ctrl+Shift+P fuzzy-searches every command. Panes are keyboard-reachable and the whole layout is navigable without a mouse.

◱

Experiments

Name, snapshot, compare, clone, and archive runs. SHA-256 provenance over datasets, sources, lockfiles, and bundles.

◆

SQL & storage

Read-only SQL workbench over SQLite, DuckDB, PostgreSQL, and MySQL; S3-compatible and rclone object storage — all credential-safe.

⇲

Offline by default

Diagnostics are off unless enabled. Nothing uploads automatically; credentials live in the OS keychain, never in project files.

The loop

Write a cell, run it, watch the plots

Cells publish visualization data straight through stdout. Metrics become live line charts, vectors become bar plots, and tables open in the full data viewer:

//# %% training loop
for epoch in 0..epochs {
    let loss = (-0.22 * epoch as f64).exp();
    println!("forge_metric:loss={loss}");
}
println!("forge_vector:weights=0.18,-0.42,0.91,0.37");
println!(r#"forge_table:sample={"columns":["x","label"],"rows":[[0.2,"cat"],[0.7,"dog"]]}"#);
Select a cell in the rail and press Shift+Enter. Metrics appear in Plots, vectors and tables in Data — click a dataset name to open the full table viewer.

Train & ship

Embedded training and native deployment

Forge embeds Burn 0.22 (Flex CPU + WGPU) and Millwright 2.2.1 ONNX. Train, register, verify, and generate a standalone Rust service — no Python required.

Native regression

Leakage-safe standardization, deterministic validation, patience-based early stopping, and original-unit loss. Predict inline or score a whole table.

Model registry

Project-local versioning with promotion/rollback aliases, immutable bytes, and SHA-256 integrity checks before every load.

Generated services

One click produces an Axum POST /predict service with health, readiness, metadata, Docker, Compose, and Kubernetes files.

Monitoring

Framework-neutral request / error / latency and explainable feature-drift tracking, with offline HTML/PDF reports and attested bundles.

Model cards, training reports, and EDA exports are fully offline HTML/PDF — no browser, no Python runtime, no network calls.

Get started

Clone and run

Forge ML is a Cargo workspace. On Windows, build from a Visual Studio Native Tools command prompt so Cargo can find the MSVC linker:

git clone https://github.com/mi7plus/forge-ml
cd forge-ml
cargo run

Then open a Cargo project, open one of the example notebooks, and press Shift+Enter. The feature guide walks through every pane in detail.
